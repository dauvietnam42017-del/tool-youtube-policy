Privacy Policy

tool youtube · Last updated: 25 October 2026

Data the tool accesses

When a channel owner signs in with Google, the tool requests access to:

  • YouTube account data (youtube, youtube.upload): to upload videos, thumbnails and playlist entries to the signed-in user's own channel, and to confirm which channel is signed in.
  • YouTube Analytics data (yt-analytics.readonly, yt-analytics-monetary.readonly): to read the signed-in channel's own performance and estimated revenue reports.

How the data is used and stored

  • Data is used only to upload the owner's videos and to display the owner's channel statistics on a local dashboard.
  • OAuth tokens and statistics are stored only on the owner's own computer. They are not sent to any server operated by the developer.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

You can revoke the tool's access at any time at Google Account › Third-party access. Deleting the token files on the owner's computer removes all stored credentials. To ask for deletion of any stored data, email the contact below.
